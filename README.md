# 🎙️ Inner Pioneers Podcast AI Agent

An automated podcast production assistant designed to streamline the **Inner Pioneers** episode content workflow. It analyses full transcripts to identify high-impact moments, extract guest credentials, and generate ready-to-publish short/long-form video captions, LinkedIn narratives, and community newsletter promotions in seconds.

---

## 📂 Project Organization

The repository is structured into standard phases to ensure clean, automated execution:

*   **`📁 Branding`**: Houses the core Evolute Brand Voice, organic lexicon, and nomenclature guidelines.
*   **`📁 Phase 1 - Episode Analysis`**: Analyses raw interview transcripts to generate deep systemic critiques, philosophical summaries, and core thematic insights.
*   **`📁 Phase 2 - Promotion Copy`**: Generates high-vigor platform captions (Instagram, TikTok, YouTube Shorts, Long-form YouTube Clips, Newsletters, and LinkedIn narratives).
*   **`📁 Phase 3 - Visual Content Creation`**: Formats hooks and insights into clean JavaScript scripts for instant Google Slides template automation.
*   **`📁 Input`**: Place your raw Riverside transcripts here to start the process.
*   **`📁 Output`**: Holds the completed promotional packages, organized cleanly by guest name.

---

## 🚀 The 4-Phase Content Workflow

### 1. Episode Analysis (Phase 1)
Identifies the core transformation, clickable angles, strongest claims, and primary resources from the transcript.

### 2. Promotional Text Content (Phase 2)
Generates the complete set of ready-to-publish promotional text and captions needed for a multi-channel episode launch:
*   **Social Media Captions**: Creates synchronized, high-vigor captions for Instagram Reels, TikTok, and YouTube Shorts.
*   **Video Titles & Hooks**: Suggests 5 attractive, strictly 6-word thumbnail titles and 5 SEO-optimized titles.
*   **Long-Form Descriptions**: Writes detailed, expert-level descriptions for short YouTube clips and the main full-length episode upload.
*   **Multi-Channel Marketing Copy**: Generates professional LinkedIn thought-leadership posts, direct team emails, WhatsApp community broadcasts, and launch newsletters.

### 3. Visual Automation (Phase 3)
Extracts key quotes, carousel slides, and thumbnail hooks, converting them into Javascript objects that can be directly pasted into Google Apps Script to auto-generate Slide graphics.
